# CashFlow Prophet

**Aplicación de pronóstico y optimización de flujo de caja** para freelancers, consultores y pymes.

## Visión
- **Predicción** de ingresos y gastos futuros usando tus históricos y el modelo de salarios (Proyecto 09).
- **Simulación** de escenarios "qué pasaría si" (más proyectos, gastos inesperados, inversiones).
- **Recomendaciones** accionables para evitar déficits de caja y mejorar la salud financiera.

## Características principales
- Conexión a tu base de datos de finanzas (`finanzas_personales.db`).
- Endpoint `/api/v1/predict-cashflow` que combina tu modelo salarial y datos de gastos.
- UI interactiva con Streamlit (sliders, gráficos, tarjetas de métricas).
- CI/CD con GitHub Actions, Docker y pruebas unitarias.
